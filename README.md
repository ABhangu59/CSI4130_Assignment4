# CSI4130_Assignment4
Repository for A4 of CSI4130 - Computer Graphics

This project leverages Three.js to create a high-performance, space-themed 3D visualization. It features a particle system for rendering dynamic effects such as stars, exhaust trails, and explosions. The application includes an interactive fly-through experience using a high-fidelity spaceship model sourced from SketchFab. The primary objective is to demonstrate advanced web-based 3D graphics capabilities.

## Features
- **Space Environment**: Realistic lighting, textures, and spatial depth to simulate an outer space setting.
- **Particle System**: Configurable particle effects for dynamic visual elements, enhancing realism and interactivity.
- **Interactive Navigation**: User-controlled spaceship movement for immersive exploration of the 3D environment.
- **High-Quality Assets**: Integration of optimized 3D models from SketchFab for professional-grade visuals.

## Execution Instructions
1. Clone the repository:
    ```bash
    git clone [repo link]
    ```
2. Navigate to the project directory:
    ```bash
    cd CSI4130_Assignment4
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Launch the development server:
    ```bash
    npx vite .
    ```
5. Access the application at `http://localhost:5173`.

## Technology Stack
